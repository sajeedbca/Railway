About Project

Project Name: Railswift – Swift and Smooth Train Reservation and Schedule Management System.

This project has been developed by Maibubsab ,Im an BCA 6th semester student at Shri Sattyam degree college, Bidar, Karnataka, as a part of my major final year academic submission.

The application leverages modern web development technologies, including Python, Django, SQLite, HTML, CSS, and JavaScript, to offer a seamless platform for managing railway reservations.

Core features of the system include train ticket booking, viewing schedules, user registration and login, and a fully functional admin panel for managing routes, trains, and passenger records.

The project reflects a strong integration of frontend and backend technologies and demonstrates real-world application of database-driven web development in the transportation domain.
